# Task: Content correctness and visual consistency

## Description

The site contradicts itself about its own numbers. `apps/web/src/data/case-studies.ts` exists so that project
copy and metrics live in one place ("One source, so they cannot contradict", `case-studies.ts:9`), but the About
page restates 73% as "errors resolved autonomously—no human intervention" while the case study labels the same
number "faster resolution" and says twice that humans approve every fix, and the hero's own log line says
"Awaiting human approval". The root meta description and the Person schema present the whole 13-year career as
AI-native development, which the site's own `/skills` page contradicts at "AI/LLM Integration, 2+" years. A
visitor who clicks a card advertising "73%" lands on a case-study page that never shows the number, a baseline or
a method. Around that sit smaller inconsistencies that make the same impression: `/work` renders a card's status
in one green and the home page renders it in another, the pre-token violet is still hard-coded in five places
outside the hero, a `/work` card announces itself to a screen reader as a 636-character link, two page-level
components and eleven CSS utilities are shipped but never rendered — ten of the eleven go here, while the
`.focus-ring` utility stays because #46 adopts it — five `create-next-app` SVGs are served from
production, three profile URLs are copy-pasted across up to nine files, and an error thrown in the root layout
falls through to Next's unthemed built-in page because there is no `global-error.tsx`. Branch:
fix/content-single-source. Lands as 3 PRs, squash-merged.
