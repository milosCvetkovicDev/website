# Task: Unjam dependency updates: Dependabot policy, advisories and toolchain versions

## Description

Dependency updates are jammed, and nothing reports it. Both open Dependabot PRs fail for reasons outside this
repository (#10: ESLint 10 against the eslint-plugin-react that eslint-config-next bundles; #9:
`@vitejs/plugin-react` 6 against vite 7), so they hold two of the five npm PR slots, and every new release in
those majors reopens a red PR. Meanwhile 40 dev-only advisories sit in the lockfile although every fix is inside
a declared range, the pinned `pnpm@10.33.0` is affected by 18 published advisories, and Dependabot alerts and
security updates are switched off on a public repository with a live site. Around that sit smaller drifts: Node
20 types on a Node 22 runtime, an `engines.node` floor below what the toolchain requires, no install delay for
freshly published versions, an unused production dependency (`@gsap/react`), and three workspace members (two
config packages and the untouched Vite starter) that nothing consumes but that generate most of the audit noise
and upgrade churn. This task writes the update policy down (one ADR, plus Dependabot ignore rules and groups),
clears everything an in-range refresh can clear, lands vite 8 and plugin-react 6 as one coordinated PR, and
turns on the alerts and security updates the owner approved on 2026-09-11. It matters because every red bot PR
occupies a slot a security fix will need, and today a green CI says nothing about advisories.

Branch: chore/dependency-policy. Lands as 4 PRs, squash-merged.
